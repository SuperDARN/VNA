# SuperDARN VNA Tools

Portable RF measurement tools for SuperDARN site visits.

This repository will hold instrument-control scripts, shared analysis helpers,
and example site configurations for vector-network-analyzer-style checks of
antenna installed paths and cable chains.

Planned tools:

- **SV4401A** — USB-serial guided OSL calibration, S11/VSWR/return-loss sweep
  capture, and cable-length-from-phase measurements.
- **Keysight FieldFox** — SCPI-over-Ethernet control-room installed-path
  screening, return-loss + DTF batch acquisition, and channel health ranking.

This is a work in progress.
